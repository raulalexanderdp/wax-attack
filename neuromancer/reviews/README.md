# Chapter reviews

One file per chapter, named `chapter-01.md`, `chapter-02.md`, and so on.

**The rule: a review never reaches past its own chapter.** Neuromancer withholds
a lot on purpose and gives it back late. Nothing here will spoil what's coming —
if something is a setup for later, it gets flagged as "worth remembering,"
never explained ahead of time.

## Format

```markdown
# Chapter N — <Part name>
*pages X–Y*

## What happened
A short recap, enough to anchor the chapter weeks later.

## What to notice
The craft and the themes — what Gibson is doing, not just what occurred.

## Gibson's vocabulary
Slang, brand names, and coinages from this chapter, translated. The book
never stops to explain itself, so this is the glossary you'd otherwise
be building in your head.

## Worth remembering
Threads that come back. Named without saying where they go.
```
